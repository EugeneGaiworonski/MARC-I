# Mechano MARC-I (16-Bit Virtual Computer Emulator)

[![Language](https://shields.io)](https://isocpp.org)
[![Platform](https://shields.io)]()
[![Architecture](https://shields.io)]()

Программный эмулятор 16-битного виртуального вычислителя **Mechano MARC-I** (*Mathematical Automated Research Calculator*) — экспериментальной ЭВМ эпохи электронно-вакуумных ламп и магнитных сердечников.

> **История развития проекта:** Изначально архитектура MARC-I была спроектирована и реализована на **Free Pascal** (`{$mode TP}`) для достижения максимальной аутентичности и совместимости с ретро-системами (DOS / Windows / Linux). Текущий репозиторий представляет собой **портирование и переосмысление системы на современном C++20** в объектно-ориентированной парадигме (ООП).

---

## Архитектурные особенности

* **Архитектура фон Неймана:** однородная память объемом **16 машинных слов** (адреса `0x0`–`0xF`), где каждая ячейка может хранить как инструкцию, так и 16-битное знаковое число.
* **Безаккумуляторная трехадресная система команд (ISA):** каждая операция связывает логические узлы напрямую с памятью без промежуточных пересылок.
* **Порядок байт:** **Big-Endian**.
* **Регистр статуса «Омега» (\(\Omega\)):** фиксирует состояние последней арифметической или логической операции с помощью трех аппаратных триггеров:
  * `Z` (*Zero*) — результат равен нулю;
  * `S` (*Sign*) — результат меньше нуля (старший знаковый бит равен `1`);
  * `E` (*Error / Overflow*) — переполнение 16-битной разрядной сетки (`[-32768..32767]`), деление на ноль или аппаратный отказ периферии.

## Формат машинного слова

Каждая инструкция занимает ровно одно 16-битное слово и делится на четыре равных 4-битных поля (тетрады):

```text
Биты:  [ 15 14 13 12 ] [ 11 10 09 08 ] [ 07 06 05 04 ] [ 03 02 01 00 ]
Поле:     ADDRESS 1       ADDRESS 2       ADDRESS 3        OPCODE
```

| Поле | Разрядность | Назначение |
| :--- | :---: | :--- |
| **ADDRESS 1** | 4 бита | Адрес первого операнда (`0x0`–`0xF`) / начальный адрес блока / подкоманда `CTRL` |
| **ADDRESS 2** | 4 бита | Адрес второго операнда (`0x0`–`0xF`) / адрес длины блока / адрес статуса `CTRL` |
| **ADDRESS 3** | 4 бита | Адрес записи результата / целевой адрес перехода `CP` / номер устройства |
| **OPCODE** | 4 бита | Код операции (`0x0`–`0xF`) |

## Система команд (ISA)

| Код | Мнемоника | Логика работы | Влияние на \(\Omega\) | Описание |
| :---: | :--- | :--- | :---: | :--- |
| `0000` | **NOOP** | — | — | Пустая операция |
| `X0X0` | **COPY** | `ОЗУ[A3] = ОЗУ[A1]` | — | Прямое копирование слова (`A2 = 0`) |
| `XXX0` | **CPYX** | `ОЗУ[A3] = ОЗУ[(A1 + ОЗУ[A2]) & 0xF]` | — | Индексное копирование (база + смещение) |
| `XXX1` | **IADD** | `ОЗУ[A3] = ОЗУ[A1] + ОЗУ[A2]` | `Z, S, E` | Знаковое 16-битное сложение |
| `XXX2` | **IDIV** | `ОЗУ[A3] = ОЗУ[A1] / ОЗУ[A2]` | `E` | Целочисленное деление (деление на `0` взводит `E`) |
| `XXX3` | **ISUB** | `ОЗУ[A3] = ОЗУ[A1] - ОЗУ[A2]` | `Z, S, E` | Знаковое 16-битное вычитание |
| `00X4` | **TR0** | `if (Z == 1) CP = A3` | — | Условный переход при нулевом результате |
| `XXX5` | **IMUL** | `ОЗУ[A3] = ОЗУ[A1] * ОЗУ[A2]` | `Z, S, E` | Знаковое 16-битное умножение |
| `00X6` | **TR+** | `if (Z == 0 && S == 0) CP = A3` | — | Условный переход при строго положительном результате |
| `00X7` | **TROV** | `if (E == 1) { CP = A3; E = 0; }` | Сброс `E` | Переход по аварии/переполнению (`A3 != 0`) |
| `0007` | **STOP** | `HALT` | — | Останов автоматического выполнения (`RUN`) |
| `00X8` | **TR** | `CP = A3` | — | Безусловный прямой переход (`A2 = 0`) |
| `01X8` | **TRI** | `CP = ОЗУ[A3] & 0xF` | — | Безусловный косвенный переход (`A2 = 1`) |
| `X0X9` | **NOT** | `ОЗУ[A3] = ~ОЗУ[A1]` | `Z, S` | Побитовая инверсия (`A2 = 0`) |
| `XXXA` | **IMOD** | `ОЗУ[A3] = ОЗУ[A1] % ОЗУ[A2]` | `E` | Остаток от деления (деление на `0` взводит `E`) |
| `XXXB` | **AND** | `ОЗУ[A3] = ОЗУ[A1] & ОЗУ[A2]` | `Z, S` | Побитовое логическое «И» |
| `XXXC` | **IOR** | `ОЗУ[A3] = ОЗУ[A1] \| ОЗУ[A2]` | `Z, S` | Побитовое логическое «ИЛИ» |
| `XXXD` | **READ** | Блочный ввод в `ОЗУ[A1..]` | `E` | Чтение массива длиной `ОЗУ[A2]` с устройства `A3` |
| `XXXE` | **WRTE** | Блочный вывод из `ОЗУ[A1..]` | `E` | Запись массива длиной `ОЗУ[A2]` на устройство `A3` |
| `XXXF` | **CTRL** | Управление устройством `A3` | `E` | Выполнение подкоманды `A1`, статус в `ОЗУ[A2]` |

## Периферийные устройства

Ввод-вывод и аппаратный контроль реализованы через полиморфный интерфейс устройств с файловой эмуляцией носителей:

* **Устройство `0` — Магнитная лента (`MagneticTape`, файлы `.TAP`):** последовательный доступ к блокам данных, перемотка (`REWIND`), пропуск/возврат записи (`SKIP_REC`, `BACK_REC`), опрос состояния (`STAT`).
* **Устройство `1` — Перфокарты (`CardUnit`, файлы `.DEC`):** подача карты из лотка (`FEED`), сброс в приемник (`EJECT`), контроль наличия карт и замятия бумаги (`STAT`).
* **Устройство `2` — Барабанный принтер (`LinePrinter`, файлы `.PRN`):** построчная печать отчетов, прогон страницы (`PAGE_ADV`), перевод строки (`LINE_ADV`), настройка табуляции (`SET_TABS`), опрос статуса (`STAT`).

## Пример программы (поиск максимума из двух чисел)

```text
Адрес   Код     Мнемоника       Комментарий
-----------------------------------------------------------------------------
0x0     CDA3    ISUB C, D, A    ОЗУ[A] = ОЗУ[C] - ОЗУ[D]; обновляются флаги Z, S
0x1     0046    TR+  0, 0, 4    Если C > D (Z=0 и S=0), переход на 0x4
0x2     D0A0    COPY D, 0, A    Ветка <= : копируем D в буфер ОЗУ[A]
0x3     0005    TR   0, 0, 5    Переход на блок печати
0x4     C0A0    COPY C, 0, A    Ветка >  : копируем C в буфер ОЗУ[A]
0x5     AB2E    WRTE A, B, 2    Вывод ОЗУ[A] длиной ОЗУ[B] на принтер (устр. 2)
0x6     0007    STOP            Останов машины
...
0xA     0000    DATA 0          Буфер результата
0xB     0001    DATA 1          Длина вывода (1 слово)
0xC     002A    DATA 42         Первое число
0xD     0063    DATA 99         Второе число
```

## Сборка (Visual Studio / MSVC)

1. Откройте решение `.sln` в **Microsoft Visual Studio 2022/2026**.
2. В свойствах проекта убедитесь, что выбран стандарт языка **ISO C++20 (`/std:c++20`)** и в *Дополнительные каталоги включаемых файлов* прописан `$(ProjectDir)include`.
3. Выполните сборку (`Ctrl + Shift + B`).
